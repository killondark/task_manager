## Context

Пустой репозиторий Task Manager без кода и окружения. Стек зафиксирован в `openspec/config.yaml`: Ruby 3.3.1 (asdf), Rails 8, SQLite, Hotwire, RSpec. Мотивация изменений — см. proposal.md — Why. Требования, которым отвечает этот дизайн — см. specs/app-bootstrap/spec.md.

## Goals / Non-Goals

**Goals:**
- Воспроизводимое окружение: Ruby 3.3.1 через asdf, локальный `.tool-versions`
- Минимальный каркас Rails 8 с SQLite, готовый к развитию
- RSpec как тестовый фреймворк по умолчанию
- Проверяемая работоспособность: корневая страница + smoke-тест

**Non-Goals:**
- Доменная модель (Task), контроллеры задач, CRUD — отдельные изменения
- API-режим приложения: работаем full-stack (ERB + Hotwire)
- Docker/деплой-инфраструктура, CI-пайплайн

## Decisions

**1. Установка Rails через `rails new` с флагами сборки**
Выполняем `rails new .` в корне репозитория с флагами `-d sqlite3`, `--skip-javascript`? Нет: Hotwire требуется. В Rails 8 `--css` для пропа не нужен, Turbo/Stimulus идут в комплекте при обычной сборке с importmap.
- *Рекомендация*: `rails new . -d sqlite3` со стандартной сборкой JS (importmap + Turbo + Stimulus). RSpec добавляем отдельно.
- *Альтернатива, отклонена*: `rails new` с Vite/ESM — добавляет Node-сборку, противоречит решению «минимум инфраструктуры».

**2. RSpec подключение**
Добавляем гем `rspec-rails` в `Gemfile`, запускаем генератор `rails g rspec:install`.
- *Альтернатива, отклонена*: Minitest по умолчанию — пользователь выбрал RSpec.

**3. Корневая страница**
Генерируем вручную статичную страницу `Home`: контроллер `home`, action `index`, шаблон с простым содержимым и подключённым Turbo. Без модели.
- *Альтернатива, отклонена*: `rails g controller`, чтобы потом не удалять ненужные сгенерированные файлы.

**4. `.tool-versions`**
Создаём на уровне корня репозитория с `ruby 3.3.1`, чтобы среда была воспроизводимой. Проверяем `ruby -v` внутри папки.

**5. Порядок установки**
Сначала `bundle install`, затем `bin/rails db:prepare` для SQLite, затем `rspec` для проверки.

## Risks / Trade-offs

- **Версия Ruby в asdf**: `asdf latest ruby` может дать иную версию, чем 3.3.1 → фиксируем её в `.tool-versions` явно, проверяем вывод `ruby -v`
- **Rails 8 и Hotwire по умолчанию**: возможные отличия от документации Rails 7 → опираться на свежие гемы и вывод `rails new --help`
- **RSpec и урлы root**: если smoke-тест падает из-за маршрутов — проверить routes.rb и скорректировать маршрут
