## Why

Проект Task Manager пуст: нет кода, нет окружения, нет даже Rails-приложения. Чтобы дальше развивать проект через OpenSpec (модель, CRUD, фильтры, статусы), нужен работающий базовый каркас Rails-приложения с зафиксированным стеком: Ruby 3.3.1, Rails 8, SQLite, Hotwire, RSpec.

## What Changes

- Устанавливается Ruby 3.3.1 через asdf с локальным `.tool-versions`
- Создаётся новое Rails 8 приложение (SQLite, Hotwire/Turbo, не API-only)
- Настраивается RSpec для тестирования
- Создаётся корневая страница, подтверждающая работоспособность каркаса
- Проект коммитится в git с игнорированием артефактов сборки/зависимостей
