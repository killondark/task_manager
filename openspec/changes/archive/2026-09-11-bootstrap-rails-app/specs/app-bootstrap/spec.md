## Purpose

Гарантирует, что проект представляет собой работоспособный каркас Rails 8 на Ruby 3.3.1, с SQLite, RSpec и Hotwire, который можно запускать, тестировать и развивать последующими изменениями.

## ADDED Requirements

### Requirement: Приложение можно установить и запустить
Система SHALL предоставлять Rails-приложение, которое устанавливает зависимости, создаёт базу данных и запускается локально без ручной настройки окружения.

#### Scenario: Установка зависимостей
- **WHEN** разработчик выполняет установку гемов в директории проекта, использующей Ruby 3.3.1
- **THEN** все зависимости приложения устанавливаются успешно

#### Scenario: Подготовка базы данных
- **WHEN** разработчик выполняет подготовку базы данных
- **THEN** SQLite-база создаётся и загружает схему без ошибок

#### Scenario: Запуск сервера
- **WHEN** разработчик запускает локальный сервер приложения
- **THEN** сервер стартует и отвечает на HTTP-запросы

### Requirement: Корневая страница доступна
Система SHALL отвечать на запрос корневого пути приложения.

#### Scenario: Открытие корневой страницы
- **WHEN** пользователь открывает корневую страницу приложения
- **THEN** страница возвращает HTTP-ответ со статусом 200 и содержит контент приложения

### Requirement: Тестовая инфраструктура работает
Система SHALL предоставлять настроенный тестовый фреймворк, который выполняет тесты по команде разработчика.

#### Scenario: Запуск тестового набора
- **WHEN** разработчик запускает тестовый набор проекта
- **THEN** все тесты проходят успешно, включая smoke-тест работоспособности приложения

### Requirement: Фронтенд работает на Hotwire
Система SHALL подключать Turbo и Stimulus стандартным для Rails 8 способом, обеспечивая работу server-rendered страниц.

#### Scenario: Подключение Turbo и Stimulus
- **WHEN** приложение отдаёт страницу с шаблоном, использующим Turbo Drive
- **THEN** Turbo и Stimulus подключены и не вызывают ошибок в консоли браузера

### Requirement: Зависимости изолированы версиями
Система SHALL фиксировать версию Ruby через локальный файл `.tool-versions` проекта, чтобы окружение было воспроизводимым.

#### Scenario: Проверка версии Ruby
- **WHEN** разработчик проверяет версию Ruby в директории проекта
- **THEN** используется Ruby 3.3.1, указанный в локальном `.tool-versions`
