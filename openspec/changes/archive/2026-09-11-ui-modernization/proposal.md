## Why

Фронтенд приложения — это голый scaffold без единой строчки стилей: пустой CSS, отсутствует навигация, список задач — браузерная таблица, а главная страница — заглушка «Каркас работает». При этом стек Hotwire (Turbo + Stimulus) уже подключён, но не используется. Интерфейс стоит привести к современному виду и добавить интерактивность в рамках уже выбранного server-rendered подхода, без перехода на SPA.

## What Changes

- Подключение Tailwind CSS через официальный гем `tailwindcss-rails`: замена пустого CSS на утилитарные стили, базовые цветовые токены и шкалы.
- Общий лейаут с навигацией (шапка со ссылками на дашборд и задачи) и стилизованными flash-сообщениями с автоскрытием.
- Дашборд на главной странице: карточки-счётчики задач по статусам, прогресс выполнения, список последних задач.
- Представление списка задач в виде карточек с цветовой индикацией статуса и приоритета вместо таблицы.
- Модальные окна создания и редактирования задач (Turbo Frames) с обновлением списка без перезагрузки страницы (Turbo Streams): карточка добавляется/исчезает/обновляется анимированно.
- Интерактивная смена статуса задачи со страницы списка (без захода в форму).
- Анимации: плавное появление и исчезновение элементов, hover-эффекты.

## Capabilities

### New Capabilities
- `ui-foundation`: подключение Tailwind CSS, базовый лейаут с навигацией, стилизация и автоскрытие flash-сообщений, базовые анимации интерфейса.
- `task-dashboard`: дашборд на главной странице со статистикой задач (счётчики по статусам, прогресс, последние задачи).
- `task-card-view`: отображение задач в виде карточек с цветовой индикацией статуса и приоритета, интерактивная смена статуса, удаление с анимацией.
- `task-modal-forms`: создание и редактирование задач в модальных окнах на базе Turbo Frames с обновлением списка через Turbo Streams.

### Modified Capabilities
- `task-crud`: сценарии создания, редактирования и удаления задач обновляются под модальный поток — форма отправляется без полной перезагрузки, список обновляется через Turbo Streams, ошибки валидации отображаются в модальном окне.

## Impact

- `Gemfile` + `tailwindcss-rails` (возможна генерация `bin/rubocop`-совместимого конфига не требуется; появятся `app/assets/tailwind/application.css` и `config/tailwind.config.js`).
- `app/views/layouts/application.html.erb` — навигация, flash, подключение стилей.
- `app/views/home/index.html.erb` и `app/controllers/home_controller.rb` — дашборд со статистикой.
- `app/views/tasks/*` — карточки, модальные фреймы, turbo_stream-партиалы.
- `app/controllers/tasks_controller.rb` — поддержка `turbo_stream`-ответов для create/update/destroy и смены статуса.
- `config/routes.rb` — при необходимости маршрут для смены статуса задачи.
- `app/javascript/controllers/*` — новые Stimulus-контроллеры (flash, modal, status, animations).
- Новые partial-файлы (карточка задачи, модальное окно, статистика дашборда).
- **Без изменений**: модели, миграции, интеракторы (`Tasks::Creator`, `Tasks::Updater`, `Tasks::Destroyer`), валидации.
