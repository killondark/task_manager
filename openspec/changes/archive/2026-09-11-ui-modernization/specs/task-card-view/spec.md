## Purpose

Отображает задачи в виде карточек с цветовой индикацией статуса и приоритета и поддерживает интерактивную смену статуса прямо из списка.

## ADDED Requirements

### Requirement: Представление задач карточками
Система SHALL отображать задачи на странице списка в виде карточек, где каждая карточка показывает заголовок, статус, приоритет и дедлайн.

#### Scenario: Отображение карточек задач
- **WHEN** пользователь открывает страницу задач
- **THEN** каждая задача отображается в виде карточки с заголовком, статусом и приоритетом

#### Scenario: Переход к задаче по карточке
- **WHEN** пользователь нажимает на заголовок карточки
- **THEN** открывается страница детального просмотра задачи

### Requirement: Цветовая индикация статуса
Система SHALL визуально различать статусы задач с помощью цветовой индикации карточек.

#### Scenario: Различие статусов по цвету
- **WHEN** в списке есть задачи со статусами `todo`, `in_progress` и `done`
- **THEN** карточки задач с разными статусами визуально отличаются друг от друга по цвету

### Requirement: Цветовая индикация приоритета
Система SHALL визуально выделять уровень приоритета задачи с помощью цветового индикатора.

#### Scenario: Выделение высокого приоритета
- **WHEN** задача имеет высокий приоритет
- **THEN** её приоритет визуально выделен цветом, отличным от задач с низким приоритетом

### Requirement: Интерактивная смена статуса
Система SHALL позволять менять статус задачи непосредственно со страницы списка без перехода на страницу редактирования.

#### Scenario: Смена статуса из списка
- **WHEN** пользователь выбирает новый статус на карточке задачи из списка
- **THEN** статус задачи обновляется, а карточка отображает новый статус без перезагрузки страницы
