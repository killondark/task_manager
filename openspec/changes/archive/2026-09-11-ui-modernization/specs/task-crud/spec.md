## MODIFIED Requirements

### Requirement: Создание задачи
Система SHALL предоставлять форму создания задачи с обязательным заголовком и необязательными описанием, статусом, приоритетом и дедлайном, доступную как в модальном окне со страницы списка, так и по прямой ссылке.

#### Scenario: Успешное создание задачи
- **WHEN** пользователь отправляет форму с заголовком «Купить продукты» из модального окна
- **THEN** создаётся задача со статусом `todo`, отображается сообщение об успехе, новая карточка появляется в списке задач без перезагрузки страницы

#### Scenario: Ошибка создания без заголовка
- **WHEN** пользователь отправляет форму с пустым заголовком
- **THEN** форма отображается снова с сообщением об ошибке валидации, задача не создаётся

#### Scenario: Ошибка создания с дедлайном в прошлом
- **WHEN** пользователь указывает дедлайн, равный вчерашней дате
- **THEN** форма отображается снова с ошибкой «дедлайн не может быть в прошлом», задача не создаётся

### Requirement: Редактирование задачи
Система SHALL предоставлять форму редактирования задачи со всеми полями.

#### Scenario: Успешное редактирование
- **WHEN** пользователь изменяет заголовок и отправляет форму из модального окна
- **THEN** задача обновляется, отображается сообщение об успехе, карточка в списке обновляется без перезагрузки страницы

#### Scenario: Ошибка валидации при редактировании
- **WHEN** пользователь очищает обязательное поле заголовка и отправляет форму
- **THEN** форма отображается снова с ошибкой валидации, задача не обновляется

### Requirement: Удаление задачи
Система SHALL позволять удалять задачу с подтверждением.

#### Scenario: Успешное удаление
- **WHEN** пользователь подтверждает удаление задачи
- **THEN** задача удаляется, отображается сообщение об успехе, карточка исчезает из списка без перезагрузки страницы
