## Purpose

Отображает на главной странице сводку по задачам: счётчики по статусам, прогресс выполнения и список последних задач со статистикой.

## ADDED Requirements

### Requirement: Счётчики задач по статусам
Система SHALL отображать на главной странице счётчики задач по каждому статусу (`todo`, `in_progress`, `done`) и общее количество задач.

#### Scenario: Отображение счётчиков
- **WHEN** пользователь открывает главную страницу приложения
- **THEN** на ней отображаются карточки со счётчиками задач по статусам и общий счётчик

#### Scenario: Счётчики при отсутствии задач
- **WHEN** в системе нет ни одной задачи
- **THEN** все счётчики отображают нулевые значения

### Requirement: Прогресс выполнения задач
Система SHALL отображать на главной странице индикатор прогресса выполнения, показывающий долю завершённых задач.

#### Scenario: Отображение прогресса
- **WHEN** пользователь открывает главную страницу
- **THEN** отображается индикатор прогресса с процентом завершённых задач

#### Scenario: Расчёт доли завершённых задач
- **WHEN** из десяти задач три имеют статус `done`
- **THEN** прогресс отображает 30% выполненных задач

### Requirement: Список последних задач
Система SHALL отображать на главной странице несколько последних задач с заголовком и статусом, а также ссылку на полный список.

#### Scenario: Отображение последних задач
- **WHEN** пользователь открывает главную страницу
- **THEN** отображаются последние задачи с заголовком и статусом

#### Scenario: Переход к полному списку
- **WHEN** пользователь нажимает ссылку на полный список задач на главной странице
- **THEN** открывается страница со списком задач
