# task-modal-forms Specification

## Purpose

Обеспечивает создание и редактирование задач в модальных окнах на базе Turbo Frames с обновлением списка через Turbo Streams без перезагрузки страницы.

## Requirements

### Requirement: Модальное окно создания задачи
Система SHALL открывать форму создания задачи в модальном окне со страницы списка задач.

#### Scenario: Открытие формы создания
- **WHEN** пользователь нажимает «Новая задача» на странице списка
- **THEN** форма создания задачи отображается в модальном окне

#### Scenario: Закрытие модального окна
- **WHEN** пользователь нажимает «Отмена» или кликает вне области модального окна
- **THEN** модальное окно закрывается без отправки данных

### Requirement: Модальное окно редактирования задачи
Система SHALL открывать форму редактирования задачи в модальном окне.

#### Scenario: Открытие формы редактирования
- **WHEN** пользователь нажимает «Редактировать» на карточке задачи
- **THEN** форма редактирования задачи отображается в модальном окне

### Requirement: Обновление списка через Turbo Streams
Система SHALL обновлять список задач через Turbo Streams после создания, редактирования и удаления задач без полной перезагрузки страницы.

#### Scenario: Добавление карточки после создания
- **WHEN** пользователь успешно создаёт задачу из модального окна
- **THEN** новая карточка появляется в списке без перезагрузки страницы

#### Scenario: Обновление карточки после редактирования
- **WHEN** пользователь успешно редактирует задачу из модального окна
- **THEN** карточка задачи в списке обновляется без перезагрузки страницы

### Requirement: Ошибки валидации в модальном окне
Система SHALL отображать ошибки валидации внутри модального окна, не закрывая его.

#### Scenario: Отображение ошибок формы
- **WHEN** пользователь отправляет форму из модального окна с ошибкой валидации
- **THEN** модальное окно остаётся открытым и показывает сообщения об ошибках
